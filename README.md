# BARRA2 downloader
By B.Duncan (2026)  
Inspired by the work of Richard Gledhill (https://github.com/richard-gledhill/barra2-dl)  

## Features making
- Allow for the loading of BARRA2 data to files as well as direct to RAM
- Across month downloading, i.e. single download file / continuous download rather than separate files which need to be later joined
